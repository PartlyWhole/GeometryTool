# Implementation plan

Approved direction: the new Geometry Whiteboard design, with actual persistent geometric constraints and a blank-board home.

1. Typed board, topology, angle references, constraint solving, transactional history.
2. Drawing and selection gestures, snapping, points on supports, camera, keyboard and touch.
3. Contextual geometric operations, angle editing, congruence, markings, recovery.
4. Persistence, portable files, exports, optional reasoning and construction tools.
5. Mathematical regression checks, rendered-browser workflows, production build and delivery evidence.

Keep previous applications untouched. Tests written during implementation are agent-authored, not independent mathematical review.
